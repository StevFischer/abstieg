# Abstieg

Descent-artiges Roguelite: Flieg durch prozedurale Minen, zerstöre den Reaktor, entkomme vor der
Explosion und steig tiefer. Zwischen den Läufen Aufrüstungen, Forschung, Module und Station ausbauen.

- **Im Browser spielen:** `index.html` (Maus, Tastatur oder Controller)
- **Downloads:** `downloads/` — Linux, Windows, Android-APK

Gebaut mit Godot 4.7.
